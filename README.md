# Knowledge Distilling

知识蒸馏相关论文调研

## 结构
- [KD/](./KD/) 下是传统通用知识蒸馏方法
- [LLMKD/](./LLMKD/) 下是大语言模型相关的知识蒸馏
- [VLA/](./VLA/) 下是VLA模型架构以及一些加速优化方法等内容
- [VLAKD/](./VLAKD/) 下是VLA模型蒸馏相关的内容
- [paper/](./paper/) 下是一些难以分类但是和知识蒸馏、VLA模型蒸馏、VLA模型等主题相关的内容
- 其他的一些md学习笔记或是文档

## 命名
所有论文pdf遵循以下命名：
- {发表年份}\_{接收会议/期刊}_{论文方法}.pdf
- 发表年份：该论文被相应会议或者期刊所接收发表的年份，如果论文没有被接收，那发表年份就是该论文展示出来的年份，比如arxiv上总会显示该论文预印本挂出来的时间
- 接收会议/期刊：是接收该论文的会议或者期刊的名称，如ICML、AAAI等，如果论文没有被接收，那么这一项为空，论文pdf命名改为 {发表年份}_{论文方法}.pdf
- 论文方法：论文主要方法的简称，如KD、DarkRank、FitNets等；如果论文没有方法（不是方法提出类文章）或者方法名称太长或者因为某些原因根本找不到方法相关的内容，则采用最能够代表该论文中心思想的一个词语
